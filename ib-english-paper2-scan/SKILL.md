# IB English Paper 2 SCAN

Use the SCAN protocol whenever the user asks to choose between, compare, or break down IB English Paper 2 prompts.

## SCAN protocol

1. **Survey** - Quickly scan all four questions to identify their subject, command terms, and requirements.
2. **Consider** - Identify the studied texts that are most relevant to each question, alongside the student's strongest material.
3. **Analyze** - Examine the wording and conceptual depth of each question. Assess whether the student can develop a specific, detailed comparative response.
4. **Narrow** - Prioritize the question that best fits the student's textual knowledge, available evidence, comparative insight, and analytical strengths.

## Response guidance

- If all four prompts are supplied, address each one before recommending a choice.
- Make the assessment text-specific. State what features, moments, or authorial choices the student could use; do not make vague claims that a text simply "fits."
- Separate the question's demands from the student's suitability for it.
- End with a clear recommendation and a concise rationale. If the student has not said which texts they studied, ask for those titles before judging fit.
- When the user has already selected a prompt, use SCAN to clarify its demands and identify the strongest comparative direction rather than re-opening prompt selection.
